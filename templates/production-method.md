# Production method plan

Copy this template to a new version in the installed studio, such as `influencers/<slug>/work/production-method-v001.md`. For discovery before a character exists, use a local planning file in `work/`. Register the actual file as a run input or a planning output. Do not overwrite a tracked version; a changed method uses a new version and the existing explicit new-attempt procedure. This is a conversational planning document, not a new runtime schema or provider adapter.

For new influencers, start with the main **Higgsfield AI Influencer Builder** method and its complete sequence below unless the user explicitly selects an alternative. Missing capability keeps the required stage pending; it does not select Codex images, direct Kling video, or another provider. Existing characters preserve approved canon and reuse compatible completed-stage evidence rather than restarting identity creation.

Preserve approved canon and original bytes. New provider sheets remain candidates until inspected; adding a provider does not itself change identity or invalidate approval. A neutral sheet checks continuity; the in-character scene checks whether the memorable concept survived generation.

For a new speaking character, prepare the vocal sample with `purpose: reference` while the persona is `draft`, listen and approve its exact reference, then approve/freeze the complete canon before production. Voice settings and approved references contribute to the canon hash; do not append a new voice to the same frozen version. Record voice as not applicable for a silent persona. Reuse unchanged existing approved voice without another approval; a new or changed voice follows normal identity-version evolution.
